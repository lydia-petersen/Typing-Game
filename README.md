## About The Project

This typing game is designed to improve typing skills and speed. Features and customization options include:
* Running multiple games at the same time and swiching between them
* Adjusting the number of words presented in each individual game
* Modifying the font size of the words
* Selecting specific words to type first

The objective of each individual game is to accurately type all displayed words to achieve victory. This game provides an engaging and adaptable way to practice and enhance typing proficiency.

## Getting Started

### Installation

If the following are not installed, follow the instructions below to set up your computer:

1. Clone the repo
   ```sh
   git clone https://github.com/lydia-petersen/Typing-Game.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```

<!-- USAGE EXAMPLES -->
### Running the game

To play the typing game do the following:

1. Navigate to the root directory in the terminal and enter the command
   ```sh
   npm run dev
   ```
2. A local URL will appear. Click on it to play the game.
